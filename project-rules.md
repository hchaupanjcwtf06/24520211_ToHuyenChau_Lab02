
# Lab 02 - Project Rules

## Engineering Rules
- Use const and let; never use var.
- Never inject untrusted content using innerHTML.
- Use semantic HTML elements.
- Use addEventListener or root event delegation.
- Keep props immutable.
- Keep state updates predictable.
- Do not use array indexes as keys for dynamic lists.
- Verify code in DevTools before committing.

## AI Workflow
1. Define a functional slice.
2. Specify its contract.
3. Implement one isolated function or module.
4. Test and review the result.
5. Commit verified work.

## Git Rules
- Use Conventional Commits.
- Keep commits atomic.
- Never commit unverified code.
